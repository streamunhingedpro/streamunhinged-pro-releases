# StreamUnhinged Pro: Windows installer

This repository hosts the official installer downloads for **StreamUnhinged Pro**, a Windows app that turns your own
stream recordings into vertical clips. It contains no source code.

## Download

Get the installer from the **Releases** page (`StreamUnhingedPro-Setup.exe`). Each release lists the file's SHA-256 in
`SHA256SUMS`.

- **Requires:** 64-bit Windows 10 22H2 or Windows 11, and an active StreamUnhinged Pro subscription from Whop (the app
  must be activated with your licence key).
- **AI model:** Setup downloads the AI model pack (about 4.8 GB) once and checks its fingerprint.
- **Windows SmartScreen:** the installer is not code-signed yet, so Windows may show "Windows protected your PC".
  Choose More info › Run anyway, and only for a file you downloaded from this page or your Whop membership.
